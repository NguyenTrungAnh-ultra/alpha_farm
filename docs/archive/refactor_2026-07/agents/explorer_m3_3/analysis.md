### 3.1 Input Data Passing Flow

1. **Data Loading**: `load_data(timeframe, start, end)` in `core_engine/BacktestEngine.py` (Lines 441–473) reads historical CSV files (e.g. `data/VN30F1M_10m.csv`) and parses the `Datetime` index.
2. **Strategy Data Access**: `AlphaStrategy.run_algorithm(df)` initializes `AlphaDataProxy(df)`. Strategies access OHLCV data as standard `pd.Series` (e.g. `self.data.pv_close`).
3. **Position Target Generation**: Strategies compute vector boolean conditions and call `self.set_positions(mask, position)`, populating target position series `pd.Series` (values e.g. `0.2`, `-0.2`, `0.0`).
4. **Lookahead Bias Prevention**: In `BacktestEngine.run(strategy, df)` (Line 198):
   ```python
   positions = positions.shift(1).fillna(0.0)
   ```
   Signals generated at the close of bar $i$ are strictly shifted to execute at the close of bar $i+1$, completely eliminating future lookahead data leakage.

### 3.2 VN30F Vectorized Backtest Execution Engine

`XNOBacktestEngine.run(strategy, df)` executes full bar-by-bar market simulation in $O(1)$ vectorized operations:

- **Contract Sizing**:
  $$\text{base\_contracts} = \text{round}\left( \frac{|\text{position}| \times \text{equity}}{\text{price} \times \text{MULTIPLIER} \times \text{margin\_rate}} \right)$$
  Where $\text{MULTIPLIER} = 100,000$ VND/point, $\text{MARGIN\_RATE} = 0.285$.
- **PnL & Netting Fees**:
  $$\text{price\_diff}[i] = \text{close}[i] - \text{close}[i-1]$$
  $$\text{pnl\_bar}[i] = \text{price\_diff}[i] \times \text{prev\_contracts}[i] \times \text{prev\_direction}[i] \times \text{MULTIPLIER}$$
  $$\Delta \text{contracts}[i] = |\text{signed\_contracts}[i] - \text{signed\_contracts}[i-1]|$$
  $$\text{fee\_bar}[i] = \Delta \text{contracts}[i] \times \text{FEE\_PER\_CONTRACT\_PER\_SIDE}$$
  $$\text{net\_bar\_pnl}[i] = \text{pnl\_bar}[i] - \text{fee\_bar}[i]$$
- **Expiration Thursday Rollover Penalty**:
  Identifies the 3rd Thursday of each month. Applies `ROLLOVER_PENALTY_POINTS = 1.5` points ($150,000$ VND/contract) plus transaction fees.
- **Intraday Margin Call Check**:
  Evaluates worst-case intraday price (`low` for long, `high` for short) against `MAINTENANCE_MARGIN_RATE = 0.185`. If equity drops below threshold, forces liquidation at breach bar and freezes equity curve at maintenance threshold.

### 3.3 Metrics Calculation (`core_engine/CalculateMetrics.py`)

- **Constant Returns Fix**:
  ```python
  daily_equity = equity.resample('D').last().dropna()
  daily_pnl_change = daily_equity.diff().fillna(0.0)
  daily_returns_const = daily_pnl_change / result.initial_capital
  ```
  Calculating daily returns relative to fixed initial capital ($1,000,000,000$ VND) prevents position scaling from distorting volatility and Sharpe ratios on growing equity curves.
- **Calculated Performance Metrics**:
  - **CAGR**: $\left( \frac{\text{final\_equity}}{\text{initial\_capital}} \right)^{1/\text{years}} - 1$, where $\text{years} = \frac{\text{trading\_days}}{252.0}$.
  - **Sharpe Ratio**: $\frac{\text{mean}(R_{\text{daily}})}{\text{std}(R_{\text{daily}}, \text{ddof}=0)} \times \sqrt{252}$.
  - **Sortino Ratio**: $\frac{\text{mean}(R_{\text{daily}})}{\text{downside\_std}} \times \sqrt{252}$.
  - **Max Drawdown**: $\min \left( \frac{\text{equity} - \text{cummax}(\text{equity})}{\text{cummax}(\text{equity})} \right) \times 100\%$.
  - **Calmar Ratio**: $\frac{\text{CAGR}}{|\text{Max Drawdown}|}$.
  - **Advanced Risk Metrics**: Recovery Factor, Kelly Criterion, Omega Ratio, Ulcer Index, 95% VaR, 95% CVaR.
